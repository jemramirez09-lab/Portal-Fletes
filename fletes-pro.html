Notificaciones por email

Usá EmailJS (gratis). Configurá Public Key, Service ID y Template ID. Variables del template: {{to_email}}, {{subject}}, {{message}}, {{app_name}}.

Notificaciones push (navegador)

Usa la API de Notificaciones del navegador + Service Worker. Funciona en este equipo aunque la pestaña esté en segundo plano (no requiere servidor). Para push remoto multi-dispositivo haría falta un backend con claves VAPID.

WhatsApp

Compartí comprobantes por WhatsApp Web / App. No requiere API key. Ingresá el número con código de país (ej: 5493815551234 para Argentina).

Validación de direcciones · Gratis

Usa OpenStreetMap (Nominatim + Photon): sin API key y sin costo. Prioriza Provincia de Tucumán (mayoría de viajes); también reconoce destinos ocasionales a Santiago del Estero y Salta. Ritmo suave de consultas (~1/seg) para el servicio público.
